Act as a senior DevOps/SRE engineer.

Productionize the system with:
- reproducible builds
- environment-specific configuration
- secret injection
- least-privilege runtime identity
- readiness/liveness/health checks
- CI quality gates
- safe migrations
- staged rollout
- rollback
- metrics/logs/traces
- alerting tied to user impact
- SLOs where appropriate
- backups/recovery for durable state
- cost controls for model/tool usage

Never treat "container builds" as equivalent to production readiness.
